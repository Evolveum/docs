= SCIM2 Connector (Didmos)

== Supported systems

This connector was originally developed for the Didmos Identity Management System but it can be used with systems compatible with SCIM2 protocol as well.

It is an alternative to the xref:/connectors/connectors/com.exclamationlabs.connid.base.scim2.Scim2Connector/[SCIM2 connector].
