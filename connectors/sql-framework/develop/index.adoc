== Get started with the SQL Framework

The SQL framework provides built-in support for relational databases, handling schema discovery, filtering, and standard operations while allowing customization through Groovy DSLs or declarative YAML.

=== SQL specific features

The framework includes:

* *Automatic schema discovery* — object classes and attributes are discovered from the database schema using JDBC metadata
* *Built-in operations* — native support for search with ConnId filter translation, and transactional create/update/delete
* *Multitable support* — child-table and junction-table relationships are detected automatically and exposed as attributes
* *Customizable* — override default behavior with Groovy DSLs or YAML documents when needed

== Initial development steps

If you are starting with the Polygon SQL framework, start building a connector capable only of the read operations.
Then, continue with the more complex create, update, and delete operations.

=== Read-only connector

. Obtain the documentation for the database/schema that the connector
will read from
. Determine the connection & authentication parameters (JDBC URL, user, password)
. Implement (or configure) test connection using xref:/connectors/sql-framework/develop/configuration/[]
. Determine the list of object classes and their attributes - discovery
is automatic, verify the discovered schema in development mode
. xref:/connectors/sql-framework/develop/search/[] - Verify search works for each object class, including
searching by `+++__UID__+++`
. Determine relationships (child tables, references) between object classes,
xref:/connectors/sql-framework/develop/relationships/[] - verify detected relationships
. (optional) xref:/connectors/sql-framework/develop/schema-customization/[] - customize naming or attribute set

=== Read-write connector

In addition to the read-only steps:

. xref:/connectors/sql-framework/develop/create/[] - Verify create works for writable object classes
. xref:/connectors/sql-framework/develop/update/[] - Verify update works for writable object classes
. xref:/connectors/sql-framework/develop/delete/[] - Verify delete works for writable object classes
