.Java version supported by midPoint
[cols="1h,1,1", options="header"]
|===
|MidPoint version |Recommended Java version |Required Java version
|4.11 and newer
|25
|21
|4.10 and older
|21
|17
|===

Other Java platform versions are not supported.
Java platform distributions based on link:https://openjdk.org/[OpenJDK] are recommended.
Other JDK builds (e.g., Oracle) may work as well, but those have a limited support for midPoint (see details in link:/midpoint/release/[midPoint release notes] for your particular version).
